SSH key pair for logging into the Linux initramfs/rootfs on the OnePlus 13 over USB (root@172.16.42.1). Generated by scripts/omarchy-build-phone.sh on first run (ssh-keygen ed25519) and baked into every image built afterwards.
Private key: never commit, never copy to the phone. Public key is packed into the initramfs as /root/.ssh/authorized_keys.
